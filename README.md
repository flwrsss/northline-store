# NORTHLINE Store

Современный интернет-магазин одежды в стиле streetwear/workwear.

## 🚀 Технологии

- **React 18** + **TypeScript**
- **Vite** для сборки
- **Tailwind CSS** для стилизации
- **React Router** для навигации
- **Framer Motion** для анимаций
- **lucide-react** для иконок
- **localStorage** для хранения данных

## 📦 Установка и запуск

### Требования
- Node.js 18 или выше
- npm 9 или выше
